## 一、功能定位

LINE 電子會員證（`card/index.html`）下方的「委託」區。**有投票資格的會員**可把「出席（主席權）」「投票權」委託給另一位有資格會員。

## 二、核心規則

| 項目 | 規則 |
|---|---|
| 委託資格 | **所有可投票者**＝有效＋榮譽＋永久＋待續約（＝`tada_v_members` 名冊，第六屆 90 人）。**不是只有有效會員**（已與使用者定案，見下） |
| 委託對象 | 只能委託給另一位有資格會員 |
| 委託關係 | 一對一：受託人同時只能持有 1 筆委託 |
| 委託權利 | 出席 / 投票，二選一或複選 |
| 生效 | **受託人不需同意，送出即生效**（不做 LINE 推播） |
| 批退（審核委託） | **受託人可「批退／退回」**已收到的委託 → 權利回歸委託人、受託人恢復可接受新委託。多人想委託同一人時，受託人須**先批退目前的**才可接受別人的 |
| 取消 | 委託人自己可取消（受託人未報到前） |
| 完全轉移 | 生效後委託人**不得再報到或投票**；權利在受託人身上 |
| 已報到鎖定 | 任一方已報到 → 委託鎖死、不可設定/取消/批退 |
| 禁止轉委託 | 已受他人委託者，不得再把自己權利委託出去 |

## 三、已定案決定（不要重問）

1. **委託資格 = 所有可投票者（含待續約）**，與投票名冊一致，不是只有有效會員。
2. **受託人不需同意、直接生效**（不接 LINE 推播）。
3. **受託人可批退委託**；要接受新委託前須先批退現有的。
4. 章節六其餘照使用者建議：報到前自動鎖定、禁止轉委託、保留稽核（時間戳＋LINE UID）、可列印電子委託書存證。

## 四、報到端連動（Phase 3，最重）

- 受託人現場報到 → 顯示「本人＋代理 1 人」：
  - 有投票權 → 發 **2 張**選票；僅出席權 → 出席人數 +1、票仍 1 張。
- 委託人若到場報到 → 擋下（權利已轉移）。
- 恢復：須委託人先取消（且受託人未報到）。

## 五、現況（已建 / 未建）

### 已建（本 session 早先）
- 資料表 `tada_v_proxy`：`election_id, principal_name, principal_no, delegate_name, delegate_no, meeting, proxy_attend, proxy_vote, principal_user_id, agreed, created_at`。
- RPC：
  - `proxy_submit(p_election, p_principal_name, p_principal_no, p_delegate_name, p_delegate_no, p_attend, p_vote, p_user_id)` — 驗證受託人是會員(`tada_v_members`)、一對一(delegate_taken)、委託人只能委託一次、寫入。
  - `proxy_mine(p_election, p_user_id, p_name, p_no)` — 回傳我送出的委託＋我是否受託(`is_delegate_for`)。
  - `proxy_cancel(p_election, p_user_id, p_name, p_no)` — 委託人取消（硬刪）。
- 前端：`card/index.html` 委託區（勾出席/投票、填受託人姓名+編號、送出、取消、顯示受託提示）。RPC 都已 grant anon。

### 未建（待做）
1. **資格閘門**：`proxy_submit` 未驗證「委託人」本身在 `tada_v_members`；card 未依資格顯示/隱藏委託區。
2. **已報到鎖定**：`proxy_submit`/`proxy_cancel` 未檢查任一方 `tada_v_members.is_checked_in`。
3. **禁止轉委託**：未擋「已是受託人者再委託出去」。
4. **批退（reject）**：需新增 `proxy_reject(p_election, p_user_id, p_name, p_no)`——由**受託人**呼叫，刪除/註銷其所受委託；card 的「您受 X 委託」需加「批退委託」鈕。
5. **狀態機/稽核**：建議 `proxy_cancel/reject` 改為**軟刪**（加 `status active|cancelled|rejected`、`ended_at`、`ended_by`），保留稽核。
6. **報到端連動**（Phase 3）：改 `vote_checkin`——委託人報到擋下；受託人報到時若持有 `proxy_vote` 委託，**多發 1 張 `tada_v_tokens`**（見技術點）。
7. **掃 QR 選受託人**（LIFF `liff.scanCodeV2`）、**後台委託清單＋匯出**、**電子委託書列印**（`print/?doc=proxy` 已存在，可重用）。

## 六、技術點（實測）

- **發票**：`vote_checkin(p_election, p_member_no)`（`card`→報到機呼叫）用**悲觀鎖 `FOR UPDATE`** 鎖會員列，設 `is_checked_in`，`INSERT tada_v_tokens(election_id,status=0)` 產生**一張匿名票 uuid**（不記錄是誰）。要發 2 票就在受託人報到時，額外為其委託人各再 INSERT 一張 token 回傳。
- **投票匿名性**：`tada_v_members / tada_v_tokens / tada_v_votes` 三表**刻意無外鍵**，勿建關聯。
- 第六屆 election id：`66666666-6666-4666-8666-666666666666`，status `open`。投票資格＝`tada_v_members` 90 人（有效+榮譽+永久+待續約，有 member_no 者）。
- `tada_members` 是主名冊；`roster_bound(p_user_id)` 回傳綁定會員 `{name, member_no, member_type, company, status, join_date}`。委託頁的「委託人」身份來自這裡。
- PAT 管理 API 走 curl `--data-binary`（python urllib 有 SSL/403 問題）；DDL 後 `notify pgrst, 'reload schema'`。

## 七、建議開發順序

1. `proxy_*` RPC 補：資格閘門、已報到鎖定、禁止轉委託、**批退 `proxy_reject`**、軟刪+稽核欄位。
2. `card` 委託區：依資格顯示、受託人「批退」鈕、已報到顯示鎖定訊息、掃 QR 選受託人。
3. **報到端**：`vote_checkin` 委託人擋下＋受託人多發票；報到機顯示「本人＋代理」。
4. 後台委託清單＋CSV 匯出（大會現場查核）。
5. （選）電子委託書列印存證。
