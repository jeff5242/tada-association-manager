# 第六屆理監事選舉 — 紙本選票設計（供 AI VLM 判讀）

**用途**：2026/9/4 會員大會現場紙本投票，投票後以手機拍照 / 掃描，交由 VLM（視覺語言模型）自動判讀計票，人工複核。

---

## 一、設計原則（為什麼這樣設計）

紙本選票要同時滿足「人好圈選」與「機器好判讀」，兩者的要求不完全相同。以下每條原則都對應一個實際會出錯的情境。

| # | 原則 | 解決的問題 |
|---|------|-----------|
| 1 | **固定版面 + 四角定位標記** | 拍照角度歪斜、透視變形 → 有定位點才能做透視校正（perspective correction） |
| 2 | **每張票印唯一票號 + QR** | 重複拍照、漏拍、票張錯序 → 可去重與對帳 |
| 3 | **勾選格為粗黑實線方框，格內留白** | 淡線框在低解析度照片會消失；格內有底紋會被誤判為已勾選 |
| 4 | **一人一列、列高一致、列間留白 ≥ 4mm** | 避免勾選記號跨列，VLM 難以歸屬 |
| 5 | **姓名用大字 + 編號雙重標示** | VLM 認錯字時可用編號交叉驗證 |
| 6 | **理事、監事分兩個獨立區塊，色帶區隔** | 避免跨區誤計 |
| 7 | **票面明印「應選 N 席」與「每票限圈 N 人」** | 兩者是不同概念（限制連記法），廢票依「每票上限」判定 |
| 8 | **底部保留「機器判讀結果」空白區** | 人工複核時可直接在票上註記 |
| 9 | **不使用淺灰、不使用彩色勾選格** | 影印/傳真會掉色 |
| 10 | **單面印刷** | 避免背面透印干擾 |

## 二、票面規格

- **紙張**：A4 直式，單面，白色 80g 以上（避免透印）
- **列印**：黑白雷射，600dpi 以上
- **邊界**：上下左右各 15mm
- **字體**：思源黑體 / Noto Sans TC，候選人姓名 20pt Bold，說明文字 11pt

### 定位標記（Fiducial Markers）

四角各印一個 **10mm × 10mm 實心黑方塊**，距紙邊 10mm。

```
■                                                    ■
   ┌──────────────────────────────────────────────┐
   │                  票面內容                      │
   └──────────────────────────────────────────────┘
■                                                    ■
```

> VLM/前處理程式先偵測四個角標，做透視校正後再切分區域，能大幅降低歪斜造成的誤判。

### 票號與 QR

- 右上角印 **票號**（例：`D-0042`，理事票 D、監事票 S）
- 票號下方印 **QR Code（20mm × 20mm）**，內容為 `TADA6|D|0042|<checksum>`
- 票號同時以**明碼大字**印出，QR 糊掉時仍可人工/OCR 讀取

## 三、勾選格規格（最關鍵）

| 項目 | 規格 | 理由 |
|------|------|------|
| 外框 | 8mm × 8mm，**線寬 0.6mm 純黑** | 夠粗才不會在壓縮照片中斷線 |
| 內部 | **全白，無底紋、無淡字** | 任何內容都可能被誤判為勾選 |
| 位置 | 每列**最左側**，垂直置中 | 位置固定，便於程式定位 |
| 間距 | 格與格垂直間距 ≥ 12mm | 避免勾選溢出到相鄰格 |
| 標示 | 格右側 3mm 處印候選人編號 | 編號與格緊鄰，綁定明確 |

**圈選方式說明（印在票頭）**：
> 請在欲支持之候選人左方空格內畫 **「○」** 或 **「✓」**，**請勿塗滿整格**。

> 為什麼不塗滿？塗滿的黑塊與印刷髒污難以區分；`○`/`✓` 是明確的人為筆跡，VLM 辨識率更高，也更容易判斷是否為「塗改後的作廢記號」。

## 六、VLM 判讀規格

### 給模型的提示詞（Prompt）

```
這是一張台灣某協會的紙本選舉選票照片。

請執行以下步驟：
1. 讀取右上角票號（格式 D-XXXX 或 S-XXXX）。
2. 由上而下，逐一檢視每位候選人左方的方形空格。
3. 對每一格判斷狀態，只能是以下四種之一：
   - "marked"：格內有明確的 ○、✓、× 或其他人為筆跡
   - "empty"：格內全白，無任何筆跡
   - "unclear"：有淡痕、污漬、或無法確定
   - "erased"：有塗改、劃掉、或重複塗寫的痕跡
4. 不要推測選民意圖。看到什麼就回報什麼。

以 JSON 回覆，不要其他文字：
{
  "ballot_no": "D-0042",
  "ballot_type": "director",
  "marks": [
    {"no": 1, "name": "陳肇浩", "state": "marked"},
    {"no": 2, "name": "唐迎華", "state": "empty"}
  ],
  "image_quality": "good | blurry | skewed | partial",
  "notes": "任何異常說明"
}
```

### 判讀後的程式端規則（**不要交給模型判斷**）

計票規則必須由程式執行，模型只負責「看見什麼」：

```
marked_count = marks 中 state == "marked" 的數量
unclear_count = marks 中 state 為 "unclear" 或 "erased" 的數量

若 image_quality != "good"        → 送人工
若 unclear_count > 0              → 送人工
若 marked_count == 0              → 廢票（空白票）
若 marked_count > 每票圈選上限     → 廢票（超額）
否則                              → 有效票，marked 者各得 1 票
```

> **為什麼分離**：讓 VLM 同時做「辨識」和「判定廢票」會讓它把兩件事混在一起推理，錯誤率明顯上升，而且無法稽核。辨識歸模型、規則歸程式，每一步都可追溯。

### 雙重判讀（建議）

每張票**跑兩次**（可用不同模型或同模型不同溫度）：
- 兩次結果**完全一致** → 採用
- 有任何差異 → **送人工複核**

實務上一致率通常在 95% 以上，人工只需處理少數。

## 七、拍照 / 掃描規範

| 項目 | 要求 |
|------|------|
| 方式 | 優先用**平台式掃描器 300dpi 灰階**；現場不便則手機拍照 |
| 手機拍照 | 正上方俯拍、**四個角標都要入鏡**、避免陰影與反光 |
| 光線 | 均勻散射光，勿用閃光燈（會反光成白斑） |
| 檔名 | `<場次>_<類別>_<票號>.jpg`，例 `TADA6_D_0042.jpg` |
| 存檔 | 原圖不修改、不裁切，另存校正後圖供判讀 |

## 八、現場作業流程

```
1. 報到     → 領票（理事票 1 張 + 監事票 1 張，票號登記於報到冊）
2. 圈選     → 投入票匭
3. 唱票前   → 監票人開匭、清點張數，與發出張數核對
4. 掃描     → 逐張掃描/拍照，即時檢查是否四角入鏡
5. VLM 判讀 → 雙重判讀，一致者自動入帳
6. 人工複核 → 處理不一致、unclear、廢票，於票面複核欄簽章
7. 結算     → 系統產出票數，監票人簽名確認
8. 存查     → 選票與影像檔一併封存
```

> **關鍵**：步驟 3 的「發出張數 vs 開匭張數」核對是整個流程的信任基礎，不可省略。VLM 只是加速計票，不取代監票。

## 九、與現行電子系統的關係

現有 `/vote`、`/election-live` 電子投票系統的資料結構可直接沿用：

- 判讀結果寫入 `tada_v_votes`，`vote_method` 標記為 `paper`
- 票號與會員身分**不建立關聯**（維持匿名性，三表不加 FK）
- `/election-live` 開票畫面可同時顯示電子票與紙本票合計

## 十一、席次與圈選上限（重要）

| 項目 | 理事 | 監事 |
|------|------|------|
| **應選席次**（章程第十六條） | 11 人 | 3 人 |
| 候補 | 3 人 | 1 人 |
| **每票圈選上限**（限制連記法） | **6 人** | **1 人** |
| 自填欄 | 3 格 | 1 格 |

> 「應選席次」是這次要選出幾位；「每票圈選上限」是**每張選票最多能圈幾個人**。
> 兩者不同，**廢票判定依「每票圈選上限」**。自填欄圈選也計入上限。

## 十二、待確認事項

1. **候選人名單是否最終定案**？目前資料庫為理事 12 位、監事 4 位候選。
2. **是否印製候補名額欄位**？章程規定得同時選出候補理事 3 人、候補監事 1 人（通常依得票序遞補，票面不需另設欄位）。
3. **團體會員代表**：一會員一票，票號發放時需確認代表人身分。
4. **票數**：有投票權會員 115 位，建議印製 **150 份**（含備用與作廢重領）。
5. **監事票用色紙**還是**僅以標題區隔**？色紙較不易混淆，但成本略高。
